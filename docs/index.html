채널명 또는 https://chzzk.naver.com/채널ID 주소로 검색해 결과 카드의 ‘추가’를 누릅니다. 저장한 카드를 누르면 VOD가 썸네일·제목·날짜 카드로 표시되고, 카드를 눌러 선택한 영상만 다운로드합니다. 치지직 계정을 연결하면 팔로잉 채널이 자동으로 추가되고, 즐겨찾기는 계정마다 따로 보관합니다.

TVer 영상은 어떻게 받나요?

TVer의 개별 에피소드 주소를 넣으세요. 일본 VPN에 연결해야 하며 다운로드가 끝날 때까지 유지해야 합니다.

취소·대기 목록은 다시 실행하면 어떻게 되나요?

대기 상태로 복원되며 자동으로 시작하지 않습니다. ‘대기열 계속’을 누르면 저장한 위치와 옵션으로 시작합니다. 필요 없는 대기 항목은 다운로드 목록에서 우클릭해 ‘목록에서 삭제’를 누르면 다시 복원하지 않으며, 기록과 영상 파일은 유지합니다. 완료 기록과 같은 영상을 추가하면 다시 다운로드할지 확인합니다.

로그인이 필요한 영상도 받을 수 있나요?

치지직 계정을 연결하면 받을 수 있습니다. 19세 영상은 본인·성인 인증된 네이버 계정이, 구독자 영상 등은 그 계정의 시청 권한이 필요합니다. 인증이나 시청 권한이 없는 영상은 받을 수 없습니다.

치지직 계정은 어떻게 연결하나요?

평소 브라우저에 Get cookies.txt LOCALLY를 설치하고 치지직에 로그인한 뒤 메인 화면 https://chzzk.naver.com/을 엽니다. 주소창 옆의 확장 프로그램 아이콘을 눌러 왼쪽 첫 번째 Export 버튼으로 chzzk.naver.com_cookies.txt를 저장하세요. 앱의 ‘설정 → 치지직 계정 → 쿠키 파일 가져오기’에서 저장에 동의하고 이 파일을 선택한 뒤 ‘가져오고 연결’을 누릅니다. 아이디·비밀번호 입력은 필요 없습니다.

로그인 쿠키는 어디에 저장되나요?

EXE 옆 .auth 폴더에 현재 Windows 사용자 계정에 묶어 암호화 저장합니다. 개발자나 별도 수집 서버로 전송하지 않으며, 인증 쿠키는 네이버·치지직 인증과 영상 조회에 전달됩니다. 다른 PC·Windows 계정에서는 쓸 수 없고, 쿠키가 만료되거나 네이버가 로그인을 해제하면 다시 가져와야 합니다. 로그아웃하면 현재 계정의 쿠키만 삭제합니다.

여러 계정을 쓸 수 있나요?

다른 계정의 쿠키를 가져오면 프로필로 추가되고, 같은 계정은 쿠키를 갱신합니다. 설정 위의 프로필 사진·이름을 눌러 계정을 전환하고, ‘새 계정 추가’로 연결 창을 바로 열 수 있습니다. 즐겨찾기와 순서는 계정마다 따로 유지하며, 로그아웃해도 목록은 남습니다.

일시정지를 누르면 받던 영상도 멈추나요?

대기열 일시정지는 새로운 영상의 시작을 멈춥니다. 진행 중인 영상은 계속 다운로드하며, 해당 영상의 취소 버튼으로 중단할 수 있습니다.

기록을 정리하면 영상도 지워지나요?

다운로드 기록에서 해당 항목과 미리보기 캐시만 제거합니다. 저장 폴더의 영상 파일은 유지됩니다.
